### 2. AI-Assisted Operations Tracker

An operational workflow designed to convert unstructured incoming requests into structured and traceable cases.

Conceptual workflow:

Incoming message  
→ Thread detection  
→ Information extraction  
→ Case creation  
→ Classification  
→ Assignment  
→ Status tracking  
→ Follow-up  
→ Reporting

The system was designed around a real operating environment processing approximately 20 requests per day.

The next evolution explores the use of AI agents to:

- Extract structured information
- Classify requests
- Recommend routing
- Detect missing information
- Generate summaries
- Surface stalled cases
- Assist human operators

The principle is not full automation at any cost.

The goal is:

**AI handles repetitive cognitive work while humans retain control over decisions that require judgment.**

## How I Build

My typical workflow is:

**1. Find the friction**

Understand where people spend time, repeat work, make avoidable errors or lack information.

**2. Model the problem**

Map actors, inputs, decisions, rules, outputs and exceptions.

**3. Define the outcome**

Identify the business metric that should move.

**4. Prototype**

Use AI, automation and low-code tools to create the fastest testable version.

**5. Add structure**

Introduce data models, validation rules, workflows, permissions and controls.

**6. Measure**

Track adoption, efficiency, quality and business impact.

**7. Iterate**

Keep what creates value. Remove what does not.
